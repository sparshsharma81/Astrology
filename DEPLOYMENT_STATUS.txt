HOW DEPLOYMENT WORKS:
═════════════════════════════════════════════════════════════

1️⃣ PUSH TO GITHUB
   git add .
   git commit -m "Vercel ready"
   git push

2️⃣ VERCEL DETECTS COMMIT
   • Vercel webhook triggered
   • Clones your repository

3️⃣ BUILD PHASE
   • Installs npm dependencies (express, node-fetch, body-parser)
   • Runs: node scripts/write-env.js
   • Creates env.js with public keys from environment variables
   • Builds serverless functions from /api/**/*.js

4️⃣ DEPLOYMENT
   • Frontend deployed to CDN
   • API deployed as serverless functions
   • Routes configured for SPA + API proxy

5️⃣ YOUR SITE IS LIVE
   • Access: yourdomain.vercel.app
   • Static files cached globally
   • API calls proxied through Vercel

NEXT STEP: DEPLOY!
═════════════════════════════════════════════════════════════

2. Click "Add New" → "Project"
3. Import this GitHub repo
