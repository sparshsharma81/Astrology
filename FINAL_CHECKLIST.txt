HOW DEPLOYMENT WORKS:
═════════════════════════════════════════════════════════════════

1. You push code to GitHub
2. Vercel webhook detects the push
3. Vercel clones your repo
4. Vercel runs: npm install (installs dependencies)
5. Vercel runs: node scripts/write-env.js (generates env.js)
6. Vercel deploys:
   • Frontend to CDN (fast global delivery)
   • /api/gemini as serverless function
7. Your site is live!

When a user visits:
1. They access yourdomain.vercel.app
2. Frontend loads from CDN
3. env.js loads with public API keys
4. They enter birth data
5. JavaScript makes API calls to:
   • OpenCage (geolocation)
   • Astro API (birth chart)
   • /api/gemini (AI narrative via serverless)
6. Full astrology report displays
