HOW TO ADD THESE TO VERCEL:

1. Go to Vercel Dashboard: https://vercel.com/dashboard
2. Click on your project (astrology)
3. Go to Settings → Environment Variables
4. For each variable above:
   - Enter the Name (e.g., OPENCAGE_KEY)
   - Enter the Value (the key value)
   - Select which environments (Production, Preview, Development)
   - Click "Add Environment Variable"
5. After adding all variables, redeploy:
   - Click "Deployments" tab
   - Click the three dots on the latest deployment
   - Select "Redeploy" to rebuild with the new variables

VERIFICATION:

After deployment, check that:
✓ Site loads at yourdomain.vercel.app
✓ Hero section displays with full styling
✓ You can input birth chart data
✓ Charts generate successfully
✓ Gemini narratives appear (no 502 errors)

If you see errors:
1. Check Vercel dashboard build logs
2. Verify all ASTRO_KEY_* are set (at least one)
3. Verify GEMINI_KEY is set
4. Check browser console (F12 → Console tab) for errors
