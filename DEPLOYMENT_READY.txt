    git commit -m "Vercel deployment ready"
    git push

  STEP 2: Go to Vercel

    Click "Add New" → "Project"
    Select your GitHub repo

  STEP 3: Add Environment Variables
    OPENCAGE_KEY, ASTRO_KEY_1-12, GEMINI_KEY
    (Copy from VERCEL_ENV_KEYS.txt)
    
    Click "Deploy" → LIVE! 🎉
